# Bean Counter Pages

Standalone support and privacy pages for the Bean Counter iPhone app.

## GitHub Pages setup

1. Create a public GitHub repository named `bean-counter-pages` under `cnoles1980`.
2. Add this local directory as its `origin`, commit, and push `main`.
3. In the GitHub repository, open **Settings** -> **Pages** and publish from the `main` branch at `/ (root)`.
4. Use these URLs in App Store Connect:
   - Support: `https://cnoles1980.github.io/bean-counter-pages/support.html`
   - Privacy: `https://cnoles1980.github.io/bean-counter-pages/privacy.html`

Before public App Store submission, add a direct support email or web form to `support.html`.
