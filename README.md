# Bean Counter Pages

Standalone support and privacy pages for the Bean Counter iPhone app.

## GitHub Pages

Publish from the `main` branch at `/ (root)`. Use these URLs in App Store Connect:

- Support: `https://cnoles1980.github.io/bean-counter-pages/support.html`
- Privacy: `https://cnoles1980.github.io/bean-counter-pages/privacy.html`

Before public App Store submission, add a direct support email or web form to `support.html`.
